## The twelve cases (default assumptions)

| Case | What sizes the system |
|---|---|
| URL shortener | 34.7K redirects/s at peak need only 3 servers; 54.8 TB over ten years needs 40 database nodes; a 6-character key fits 36.5 billion links with 1.6x headroom |
| Pastebin | 174 reads/s on one server; 110 TB of paste bodies belongs in object storage |
| Distributed rate limiter | 174K checks/s need 3 counter-store shards; counters take only 4 GB |
| News feed | 1.39M feed inserts/s if every post is pushed, against 69.4K feed reads/s; a celebrity post takes 100 s to fan out |
| Chat | 100M concurrent connections need 1,429 gateways; 694K messages/s are only 278 MB/s |
| Notifications | 34.7K/s on 25 workers, but SMS costs $375K a day |
| Web crawler | 386 pages/s and 309 Mbps, yet 579 fetches in flight by Little's law; 2.52 PB for a year |
| Search typeahead | 347K requests/s at peak; a 100 GB index fits in memory on each of 10 servers |
| Ride hailing | 250K location updates/s into a 300 MB live index; 720 GB/day of history if kept |
| Video streaming | 22.2M concurrent viewers, 111 Tbps at peak; 11.7 PB/day new storage; 120K transcoding cores |
| File sync | 1.05 EB physical after dedupe and erasure coding; 694K metadata operations/s at peak |
| Metrics monitoring | 6.67M samples/s compress to 789 GB/day; 100M series need 18 ingesters by memory |

## Quality control (DMAIC)

| Phase | This repository |
|---|---|
| Define | Back-of-envelope estimates in system-design interviews and reviews are often hand-waved, hard to check and hard to redo when an assumption changes. M1 counts when twelve cases state requirements and reasoned assumptions, a JavaScript calculator computes every estimate from formulas stored as data, a sensitivity pass names the drivers, generated docs cannot drift from the numbers, and Java recomputes every case to match JavaScript ([RFC 0001](../rfc/0001-design.md)). |
| Measure | `make test` and `make lint` on an Intel Core i7-13700H with Windows 11 (Node.js 24.19.0, OpenJDK 21.0.12), plus `npm audit`. 46 tests passed (JavaScript 21, Java 25), 0 failed; every estimate of all twelve cases matched across languages to 1e-12; headline values include 34.7K redirects/s on 3 servers for the URL shortener and 1,429 gateways for 100M chat connections. |
| Analyze | Two defects are recorded. A first sensitivity version reported one biggest driver per estimate, picked alphabetically, which hid inputs with equal effect and the sign of denominator inputs (ADR 0003). Before the 2026-10-06 security recheck, a formula nested deeply enough could overflow the stack instead of failing with a clear error. Prototype measurements against the estimates are not measured yet (M2). |
| Improve | The sensitivity table now lists every tied driver with its signed change and labels step values; formulas nested over 100 levels or longer than 2,000 characters are refused with a `FormulaError`, with tests in both languages. |
| Control | The `ci` workflow's `build` job runs `make ci` (javac `-Xlint:all -Werror`, `tsc --checkJs --strict`, a check that generated docs and expected values are current, and both test suites) and `make audit` (`npm audit --audit-level=high`, and OSV-Scanner on a CycloneDX SBOM of every resolved Maven dependency, added 2026-10-07) on every push and pull request. In the code, formulas are parsed by a small grammar and never passed to `eval`, may only use names defined earlier, case files are validated (units, reasons, headlines), and case ids can only name files in `cases/` (ADR 0002). |
